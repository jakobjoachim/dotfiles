## What I do

You should use the gitlab merge request mcp to read the comments on the relevant merge request.

## How to do the review

- go over the comments one by one
- check if the comment has merit. 
- analyse the code if necessary to find a good solution that fits the architecture
- Using the question tool provide the user with a suggestion on how to solve it, either by commenting / resolving or changing code

Also check general comments on the mr for any todos
